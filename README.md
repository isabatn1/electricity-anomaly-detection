
# Elektrik Tüketiminde Anomali Tespiti

Bu projede, bir hanenin yaklaşık dört yıllık elektrik tüketim verilerini Python kullanarak analiz ettim. Günlük tüketim değerlerini hesapladıktan sonra Isolation Forest ve istatistiksel yöntemlerle normalden farklı tüketim gösteren günleri ve dönemleri inceledim.

Çalışmada Pandas, NumPy, Matplotlib ve Scikit-learn kullandım.

## Veri Seti

[Individual Household Electric Power Consumption (UCI)](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)
